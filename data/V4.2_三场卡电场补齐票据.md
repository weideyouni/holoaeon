## 一、这一批做了什么

1. **三场口径先定死**：三场 = 磁场 / 电场 / 液态场（1331 三场药理口径），场 id 固定 `magnetic / electric / liquid`，不许造第四场。
2. **宿主侧卡片登记 13 张**（自写文字，不抄客仓）：磁 5（rTMS 低频 / rTMS 高频 / PEMF 骨不连 / PEMF 膝骨关节炎 / rTMS 慢性期-痉挛-认知）、电 3（tDCS / TENS / 电针）、液 5（脂质体 / 柔性囊泡 / 甘油体 / 磷脂复合物 / 植物纳米囊泡）。场分布与客仓 `sanchang_field_evidence.csv`（13 行、磁 5 / 电 3 / 液 5）**只对齐计数、不复制正文**。
3. **电场 3 张全部做结构化补齐**：原客仓这 3 张是 `status=gap`、`evidence_tier=none`、无参数。本批把它们补成 `gap_structured`——
   - 参数维度：tDCS（电流强度口径/极性/部位/单次时长/疗程）、TENS（频率/脉宽/电流强度口径/电极位置/疗程）、电针（频率/波形/电流强度口径/留针时长/穴位方案）；
   - 检索计划：库（PubMed / Cochrane / CNKI）、≥3 关键词、纳入/排除、`decision=none`、`next_action`；
   - 顶替禁令：磁证据不得顶电、电证据不得顶磁，手针与 rTMS 不得顶电针。
4. **补齐 ≠ 补出证据**：补的是「可执行的空白卡」，`evidence_tier` 仍为 `none`，结论字段恒 `none`，等原始文献回填。磁 1 张（TF-M-05）一并按同口径结构化（4/4 gap 全部结构化）。
5. **红线闸**：`guard()` 拦剂量数值（数字+剂量单位）、疗效承诺（治愈/总有效/显效率/推荐使用/替代药物/可停药）、接设备/下参数处方、临床诊断四类，命中即 `blocked`，不降级口径。

## 五、许可与边界

- 客仓 MPL-2.0 数据件**只读互认**：只比行数与场分布，命名、人群、来源一律不抄；宿主文字自写，避免许可混入。
- 不接设备、不下参数处方、不写剂量、不做诊断、不写疗效；补的是「参数维度 + 检索计划」，不是治疗方案。
- `L4/L5` 卡片一律标注「体外/动物/早期研究不得外推人体」，`no_human_extrapolate` 口径与客仓一致。

## 六、缺口与边界（本批不做）

1. **不做证据回填**：4 张 gap 卡的 `evidence_tier` 仍为 `none`，需真实文献检索后按原始文献回填，回填前严禁改等级。
2. **不做跨场合并**：磁/电/液各自独立，不建「三场通用卡」；跨场组合属 V4.3。
3. **不改客仓**：客仓 `sanchang_field_evidence.csv` 及其 `SHA256SUMS` 全程未写，ivsa 21/21 不受影响。
4. 电场 3 张的「人体证据」仍为空，本批只把空白卡补成可执行卡，**不等于补齐证据**——这是医学红线的硬边界。
