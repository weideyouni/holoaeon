# 视频文字张量化 DNA

一句话：**先用指纹把文字钉死，再从钉死的表里读规律**。

```
① 取文   妙记转写（唯一合法来源，拒绝网页/元数据代替）        → transcript.txt
② 切段   说话人块 + 毫秒时间戳，断言段数/总时长               → blocks.json
③ 定轴   冻结概念轴，先查空列再谈统计（空列=词表选错）        → axes profile
④ 成张   稀疏计数矩阵 + 四阶规格 + 单值指纹                   → concept_matrix.csv / tensor_spec.json / digest.txt
⑤ 提律   每条规律必须能指回一张具体的表或一个具体的段           → 规律清单
⑥ 图证   双面板静态 SVG，重叠复检到 0 才准交                  → 结构图
```

## 为什么必须这样排

| 顺序 | 跳过的代价（真实发生过） |
|---|---|
| ② 在③之前 | 段切错，后面所有统计都在错的粒子上算，且看不出错 |
| ③ 在④之前 | 词表选错会表现为「矩阵很稀疏、看着挺合理」，而不是报错 |
| ④ 在⑤之前 | 没有指纹，规律随时会因为手改一处数字而整体失真且无法察觉 |
| ⑥ 最后 | 图先画会把「想让人看到什么」的偏见固化进数据 |

## ① 取文

用 `doubao-video-extract` 的转写链路（`--run-lark`），产物落 `minutes/artifact-*/transcript.txt`。
硬规则：**内容只能来自转写产物**；浏览器页面、标题、简介、评论区一律不得替代。

## ② 切段

```bash
python scripts/build_tensor.py --transcript <transcript.txt> --out <输出目录>
```

切分正则默认 `Speaker N HH:MM:SS.mmm`。产出的 `blocks.json` 里每段带 `i / t / text / chars / questions / numerals / concept_hits`。

必查三条：
- 段数 = 转写里 `Speaker` 标记数（不是行数）
- 末段 `t` ≈ 视频时长（差 30 秒以上说明漏了尾部或片头被并进第一段）
- 每段 `chars` > 0（空段会被跳过，跳过的段数要记账）

## ③ 定轴（最容易出错的一步）

概念轴是 d1 维，**一经确定就冻结**：扩轴意味着旧指纹作废，样本之间不可比。

24 轴默认档（`references/axes-profile-space.md`）：空间 / 时空 / 牛顿 / 莱布尼茨 / 爱因斯坦 / 广义相对论 / 引力 / 引力波 / 黑洞 / 质量 / 时间 / 光年 / 实验 / 观察 / 天文台 / 刚性 / 弹性波 / 能量 / 量子 / 量子纠缠 / 涌现 / 信息 / 微观 / 宇宙。

> 词必须取自**原文实际用词**，不能取近义词。上一版把「观察」写成「观测」，结果该轴全篇 0 命中——矩阵照样算得出来、稀疏度照样漂亮，只有回读原文才发现是空列。

定轴后立刻跑：

```bash
python scripts/audit_axes.py --dir <输出目录>
```

判据：空轴数 = 0；冷轴（命中 ≤1）不超过轴的 1/6；单段 distinct 最大值 ≥ 8（否则说明轴太粗，24 列在重复同一件事）。

## ④ 成张

四阶规格：`d0 语段 × d1 概念 × d2 特征 × d3 认知层`
- d2 特征四维：出现频次（现算）／论证角色／证据等级（5 级）／认知层级（3 层）
- d2 的后三维是人工标注的 ordinal 值，**不进指纹**——指纹只覆盖可复算的计数部分

指纹口径（不可改）：

```
sha256( json.dumps([[i, t, chars, questions, n_num] + 概念计数行 ...],
                   ensure_ascii=False, separators=(",", ":")) )
```

改轴、改段、改切分都会让指纹变；改人工标注不会。这就是「哪些是事实、哪些是我贴的标签」的分界线。

## ⑤ 提律

八条规律模板（见 `references/axes-profile-space.md` 末节）：证据分布 / 概念首现序 / 段长与论点比 / 设问密度 / 数字可校验性 / 回扣结构 / 免责强度 / 类比的层级跨越。

每条规律必须写成「结论 + 支撑统计 + 可复核位置」三联。写不出支撑统计的，降级为观察，不写成规律。

## ⑥ 图证

静态 HTML/SVG 双面板：面板 A 是「层级 × 证据 × 篇幅」的散点，面板 B 是「概念首现阶梯」。
输出必须是 ` ```html type="renderer" ` 契约（唯一 `<title>`、禁 DOCTYPE/head/body、根容器自然撑高）。
交图前跑重叠复检：

```bash
python scripts/check_viz_overlap.py --html <结构图.html>
```

退出码 0 才算通过（当前基线：42 个文本节点、重叠 0）。

## 验收判据（逐条可判定）

- **A1 取文合规**：产物路径来自 `minutes/artifact-*/`，不是网页。
- **A2 切段自洽**：段数 = Speaker 标记数；末段时间与视频时长差 ≤ 30 秒；无空段。
- **A3 轴不空转**：`audit_axes.py` 空轴数 = 0。
- **A4 指纹可复算**：同一输入连跑两次 digest 相等；改动任意一段正文，digest 必变。
- **A5 标注不污染**：删掉全部人工标注后重跑，digest 不变。
- **A6 规律有据**：每条规律都能指到具体表行或具体段号。
- **A7 图可读**：初始静态即可读懂主结论；重叠复检 0；无 100vh。
- **A8 旁挂纪律**：不新增智能体/技能注册、不改既有黄金值、不改主核行为。

## 已知坑

见 `references/pitfalls.md`（12 条，全部真实踩过）。最常犯的三条：近义词冒充原文词、「minute not ready」误判为失败而重跑、用行数或稀疏度漂亮当验收。
