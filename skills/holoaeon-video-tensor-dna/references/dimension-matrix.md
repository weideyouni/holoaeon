# 同维度横评：三条技能线放在同一张表里

三个技能是同一套工程骨头的三种用法：**先钉死一个可复算的单值，再谈叙事**。

| 维度 | holoaeon-v2-empower-upgrade | holoaeon-release-sync-dna | holoaeon-video-tensor-dna（本技能） |
|---|---|---|---|
| 一句话定位 | 已冻结维度的系统做旁挂式升级 | 一条链三落点，一个摘要字符串验收 | 一段口播压成张量，再从张量读规律 |
| 结构 | 五段式：探微→筑基→构弦→持衡→综合 | 三跳：本地→Gitee→GitHub，HF 侧镜像 | 六步：取文→切段→定轴→成张→提律→图证 |
| 不变量 | 智能体/技能/包/单测/自检数字全不动 | 提交字节不动，`.github/` 是唯一允许差异 | 概念轴冻结；人工标注不进指纹 |
| 单值判据 | 篡改 N/N 必变、DIFF=0 保持旧黄金值 | 对象摘要哈希三端逐字符相等 | sha256(段号+时间+字数+问句数+数字数+概念计数行) |
| 验收条数 | A1–A9（9 条） | A1–A4（4 条） | A1–A8（8 条） |
| 失败模式 | 恒真空转、同集自证、静默变黄 | CRLF 假同步、行数当验收、半通网络 | 空轴空转、近义词冒充原文词、漂亮稀疏度 |
| 硬化手段 | fail-loud（红只许变红） | 服务端对齐 + 只读验收 | 空轴即 FAIL、重叠即 FAIL |
| 坑表 | G-1…G-8（8 条） | 12 条 | 12 条 |
| 产出 | 证据行 + 快照 + 投喂包 | 三端 PASS 回执 | 矩阵 CSV + 规格 JSON + 指纹 + 结构图 |
| 落地形态 | 旁挂脚本与证据文件 | 旁挂执行器脚本 | 旁挂技能目录（本仓库 skills/） |

## 三条共同骨（这才是可复用的部分）

1. **先有反例，再谈正确**：V2 用随机篡改造反例；同步线路用「Gitee 单独前进、GitHub 追不上」造反例；本技能用「空轴」造反例——三者都是先证明「坏了看得出来」，才谈「好了是什么样」。
2. **验收只认单值**：不是「看着差不多」「文件都在」，而是一个字符串。字符串不等就是不等。
3. **人工判断与机器事实分栏**：标注（角色/证据/层级）、角色表、站点角色表，都不进被哈希的字段。

## 本技能与前两者的差异（为什么要单独立一条线）

- 前两者处理的是**工程状态**（维度、字节、提交），本技能处理的是**语义内容**。
- 前两者的反例是「构造出来的」（篡改、脏树）；本技能的反例是「自然发生的」——写错一个词，整列静默归零，矩阵照样算得漂亮。
- 所以本技能把体检前置到定轴这一步，而不是像前两者那样放在收尾。

## 组合用法（装进 HoloAeon 体系后）

```
取文（doubao-video-extract 转写）
  → 本技能成张 + 提律
  → 产出的矩阵/规格/结构图按 holoaeon-release-sync-dna 三地同步
  → 若要扩轴或升版，按 holoaeon-v2-empower-upgrade 的旁挂纪律：旧档另存，不许原地覆盖
```

三者串起来正好是一条完整线：**内容进（本技能）→ 体系装（V2 范式）→ 三地出（同步 DNA）**。
