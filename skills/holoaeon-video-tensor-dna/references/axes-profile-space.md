# 轴档：24 概念 + 八条规律模板

## 24 轴默认档（顺序即指纹顺序，改动等于换档）

空间、时空、牛顿、莱布尼茨、爱因斯坦、广义相对论、引力、引力波、黑洞、质量、
时间、光年、实验、观察、天文台、刚性、弹性波、能量、量子、量子纠缠、涌现、信息、微观、宇宙。

选轴三条：**原文用词优先**、**可被一句设问点名的实体优先**、**能跨越三个以上语段的长寿词优先**。
「宇宙」这种全篇铺开的词必然满列；「刚性」这种只在一段出现的词恰恰是定位段落的路标，两种都要留。

## 扩轴三原则

1. **不原地改**：新概念另立 profile（`--axes` / `--axes-json`），旧档案与其指纹原样保留。
2. **只加不换序**：新轴追加在尾部，已有轴的列下标不动，历史矩阵仍可并表。
3. **加完必查空列**：新轴若全篇 0 命中，说明取词想当然，回去读原文。

多视频对比时：轴冻结、样本增长。同一档轴下 N 个视频 = N 张同形矩阵，可直接做逐列对比（哪个概念在哪个作者那里出现得早、出现得密）。

## 八条规律模板（每条都要能指回一张表或一段）

| 编号 | 规律 | 支撑怎么取 |
|---|---|---|
| R1 | 证据前重后轻 | d2 证据等级 × d0 段序：5 级证据落在哪些段，是否全在前段 |
| R2 | 概念首现单调升级、不回头 | `first_seen` 序列是否严格递增且无回退 |
| R3 | 单段 ≈ 一个论点 + 一个设问 + 1~2 个数字 | chars / questions / n_num 三段分布 |
| R4 | 设问密度恒定 | questions_total ÷ duration_s，密集段单独点名 |
| R5 | 数字全是可校验常量 | numerals 逐条回读原文，区分「常量」与「评价词」 |
| R6 | 回扣开头 | 首段实体在后段复现的位置（概念矩阵里同列再次非零） |
| R7 | 猜想必带免责，且与主张强度反相关 | 论断强度（证据等级）与该段的限定语数量 |
| R8 | 类比承担层级跨越 | d3 层级跃迁点前后的段落是否都是类比型 |

写不出支撑统计的，降级为「观察」，不写成规律。
