## 一句话

让一个没有 GPU 的老机器、一个不懂代码的新手，用对话界面（豆包/千问/元宝随便换），就能可靠地干出「亚专业复杂辅助工程」级别的活——每一步可复算、可审计、算力经济。

## 五个验收标尺（唯一标尺，矩阵大小/节点数不再是尺子）

| 标尺 | 含义 | 验收方式 |
|---|---|---|
| ① 普通硬件 | 无 GPU、4GB 内存、Python 3.8+ 的老机器能跑 | 在最低配机器上跑 selftest 25/25 |
| ② 零门槛 | 不懂代码的新手用对话界面操作 | 小白按一个键，看到「校验通过」 |
| ③ 对话前端 | 豆包/千问/元宝任意对话前端驱动同一确定性引擎 | 三个前端跑同一任务，回执哈希一致 |
| ④ 确定性 | 同输入同输出，逐位可复现 | diff0_hash 逐位复现 |
| ⑤ 可审计 | 每一步留痕，答不出的明确说没有 | evidence-chain 全链 + fail-loud |

## 定位（不可移动的边界）

- **是**：辅助研究与教学的知识工程引擎 + 技能生态
- **不是**：诊疗系统（医疗软件要资质；`evidence_class=simulated`、零剂量、碳基终裁既是纪律也是法律护城河）

## 四个商用前提（必须全部达成才可商用）

| 前提 | 当前状态 | 目标 |
|---|---|---|
| ① 权限闸门 | ❌ 缺失（L4 是整数级别，无路径级细粒度） | 内核只读 + 写需显式授权 + Bash 细粒度闸门 |
| ② 最小可运行交付 | ❌ 缺失（无 install 脚本，pyproject.toml 有但不一键） | 老机器一条命令装好 + 对话前端驱动 |
| ③ 诚实验收报告 | ⚠️ 部分（evidence-chain 有，但无产品级验收报告） | 能做什么/不能做什么/每步哈希回执 |
| ④ 文档与实物对齐 | ❌ 1600 味库大词无实物 | 要么接入要么删词 |

## 红线（不可移动）

- S1 不扩大物理上限
- S2 取舍必须留痕
- S3 代价必须显式
- S4 可逆优先
- N7 声称未测过的事即造假
- `evidence_class=simulated` / 零剂量 / 碳基终裁
