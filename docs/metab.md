## 1. 设计概述与定位

METAB 是本系统的代谢系统：它决定系统摄入什么能力与知识、如何消化、吸收进骨架多少、
如何排出、以及哪些能力只是"共生"而非"自身"。它不是插件管理器，而是**能力与知识进入系统的
唯一受治理通道**——任何绕过该通道的摄入，在本文口径下一律视为缺陷。

METAB 只做判定，不做执行。它输出四类结论：准入与否、归哪一态、缺什么、凭什么拒绝；
实际开关、实际挂载、实际回滚由用户完成。原因是三条公理的第一条：摄入主权归用户。

它保护了哪条公理：公理1（METAB 只给判定与证据，不代签授权）。

## 2. 术语表

| 术语 | 定义 | 可判定标准 |
|---|---|---|
| **共生体（Symbiont）** | 一次"赋能升级"的统一封装单位：一种策略、一个探针集、一套表达模板、一个外部能力、一个外部知识源 | 一份提案只有一条基因组且只对应一个能力族，才算一个共生体；一个提案描述两个能力族须拆成两个 |
| **基因组** | 共生体携带的六条染色体（表型/纯度/血统/毒性/耗能/节律） | 六条齐备且每条子字段齐全即合格；缺任一条即不准入 |
| **染色体** | 基因组的一条，描述共生体的一个可判定侧面 | 每条须能回答"合格/不合格"，不含"较好""适中"这类不可判定措辞 |
| **纯度** | 对来源可靠性的四级标定：官方文档级 / 公开语料级 / 行为推断级 / 黑箱借用级 | 每条外部材料必须落在四级之一；同一材料不得同时标两级 |
| **血统** | 来源、许可、概念传染性判定、哈希链 | 四个字段齐全，且哈希链能从首节点验到末节点 |
| **传染性** | 某理论框架进入骨架后强制改写下游表述口径的性质 | 判定为 none / local / downstream 三级；downstream 者不得进主干 |
| **隔离区** | 允许使用但不进入主干骨架的存放区 | 存放于隔离区的共生体，其能力可被调用，但其术语不得出现在主干表述中 |
| **毒性** | 爆炸半径、不可逆点、降级路径三者合一的风险描述 | 无降级路径即否决；不可逆点必须显式（写"无"也算显式） |
| **耗能** | 算力、存储、外部调用、对用户注意力的打扰配额 | 四项各有量或显式"零"；注意力配额缺省即否决 |
| **节律** | 所属插拔态、依赖与被依赖关系、卸载成本 | 依赖须显式（空也要写空），卸载成本须给出 |
| **呼吸态（热）** | 只改策略、倾向、模板、阈值、探针节奏的变化 | 在 tick 边界生效，即时中止 |
| **循环态（温）** | 改通路、规则集版本、路由表的变化 | 需一次心跳屏障对齐后生效，回滚到上一屏障快照 |
| **代谢态（冷）** | 改骨架、索引、基线、长期权重、主干槽位的变化 | 在 checkpoint 边界生效，须冻结快照与回归验证 |
| **假饲（Sham Feeding）** | 只计算不生效，与现行系统同场对比，产出增益报告 | 有对比数据、有样本量、有结论（正/不足以判断/负）三者才算完成假饲 |
| **灰度** | 按时间、比例或任务类型小范围生效，且冻结回滚锚点 | 有锚点哈希、有范围描述、有中止条件三者才算完成灰度 |
| **共生** | 正式挂载，写入血统账本与共生体注册表 | 注册表有条目且血统账本有对应记录即完成 |
| **休眠** | 熔断或用户关闭；通路切备用路径，赫布协作边冻结而非抹除 | 备用路径可用、协作边状态为"冻结"、脏状态清单为空三者同时满足 |
| **归档** | 保留可复现包（配置、血统、效果报告、重建引用、哈希） | 六件齐全才可标"已归档"，否则只能标"归档未完成" |
| **禁食态** | 离线模式：断网时仅运行自有骨架 | 断开外部通道后系统仍可启动、且黑箱借用类自动不可用，即满足 |
| **借来的信念** | 依赖不可审计外部能力的结论 | 结论的任一依赖未通过审计，该结论即标"借来的信念" |
| **信任半径** | 外部能力能看什么、能返回什么、出问题退到哪里 | 三项齐全才可登记；缺任一项即不得挂载 |
| **组合白名单** | 允许同时生效的共生体类别配对清单 | 白名单外的配对默认不生效；白名单变更本身是一次循环态变化 |
| **摄入主权** | 授权只能由用户作出的原则 | 系统任何自行开启/放宽/记住的行为都记为越权 |
| **一键禁用** | 立即停止生效并切备用路径的动作 | 执行后生效面归零；它**不等于**骨架回滚（见 K6 消解） |

## 3. 公理与决策优先级

### 3.1 三条公理与裁决顺序

| 优先级 | 公理 | 本文的可判定表述 |
|---|---|---|
| P1 | 摄入主权归用户 | 任何"系统替用户开启/放宽/记住"的实现判为越权；任何默认开启项判为违规 |
| P2 | 可逆优于更强 | 任何无回滚锚点即生效的实现判为缺陷；不可逆操作不得作为默认路径 |
| P3 | 可溯源优于可用 | 任何无法回答"从哪来、经过谁、被谁改写"的知识进入主干，判为违规 |

裁决规则（冲突时按序）：

1. 先查 P1：是否替用户做了授权决定。是→拒绝，不再讨论收益。
2. 再查 P2：是否可在无快照的情况下中止。否→降级为更低侵入的形态，或要求先立锚点。
3. 再查 P3：是否能给出完整血统。否→只能进隔离区，不得进主干。
4. 三者均满足后，才允许就该设计的收益与成本做取舍。

它保护了哪条公理：三条同时，顺序即优先级本身。

### 3.2 八处内在冲突与消解（先指冲突，再给两种方案，再选取）

投喂规格内部存在八处互相拉扯的约束。逐条列出，A/B 为两种消解方案，chosen 为本文采用者。

| # | 冲突点 | 方案 A | 方案 B | 采用 | 理由 |
|---|---|---|---|---|---|
| K1 | 公理2「不可逆记为缺陷」 vs 「毒性红者二次确认并明示不可逆点」 | 红级一律拒绝 | 红级可挂载，但不可逆点须搬到系统外（用户侧）并留外部回滚锚点 | **B** | 红线要求的是"有降级路径"而非"零不可逆点"；把不可逆点限定在系统外，系统内仍可逆，两公理同时成立 |
| K2 | 允许"黑箱借用级"纯度 vs 「无血统者不得进主干」 | 删除黑箱级，只留三级 | 保留黑箱级但限定隔离区/外部位，强制标借来信念、禁食态不可用 | **B** | 删级会掩盖真实存在的外部依赖；分级+分区同样能挡住它进主干 |
| K3 | 「皮肤已存在，METAB 对接不重造」 vs 「皮肤充当摄入门户与免疫门禁」 | METAB 只调用皮肤既有判定，不新增规则 | METAB 在皮肤上注册"摄入专用规则"作为追加层 | **A** | 追加层等于重造免疫，会与既有权衡打架；METAB 只把许可/信任半径/不可逆确认作为入参交给皮肤 |
| K4 | 「探针投放属呼吸态，随时启停」 vs 「摄入主权归用户」 | 探针每次启停都要会话级授权 | 节奏归内分泌层（周级一次授权），单次启停仍走反射层 | **B** | 周级管节奏、会话级管单次，粒度分开既不越权，也不把用户拖进每拍打扰 |
| K5 | 「双通道禁止传原文」 vs 「蒸馏是建构通道执行者」 | 解构通道持原文只读权、只出结构；建构通道只见结构 | 允许建构通道读"去标识摘录" | **A** | B 的"摘录"仍是原文片段，等于给禁令开后门；A 用职责分离把禁令变成结构约束 |
| K6 | 红线「无法一键禁用不予挂载」 vs 代谢态「回滚成本高」 | 一键禁用=立即停效并切备用路径，骨架回滚另走代谢态 | 一键禁用必须同时回到上一 checkpoint | **A** | B 把"停止伤害"与"恢复历史"绑死，反而让人不敢用；A 让止损即时、恢复可控 |
| K7 | 「未知组合默认不生效」 vs 代谢态引入新依赖必然产生新组合 | 白名单随代谢态一起发布，白名单变更即代谢态 | 白名单变更属循环态（规则集版本），新增节点仍属代谢态 | **B** | 白名单是路由/放行表，按四问 Q4 属循环态；新增节点仍受代谢态约束，两者不冲突 |
| K8 | 「不可逆事件数恒为 0」 vs K1 允许系统外不可逆点 | 恒零只统计系统内事件，系统外单独记台账 | 恒零覆盖系统内外，红级永久不可挂载 | **A** | 指标必须可达成才有约束力；外部点单独记账，可追溯性不降 |

它保护了哪条公理：K1/K6 服务 P2，K2/K5/K8 服务 P3，K3/K4 服务 P1。

## 4. 共生体基因组规范（六条染色体）

准入总则：**六条缺一即不准入**；每条都必须可判定，不得使用"较好""适中""影响较小"这类
无法判断是否违反的措辞。

| 染色体 | 字段 | 合格判据 | 不合格示例 |
|---|---|---|---|
| **表型** | `does` / `produces` / `not_do` | 正向职责、产出形态、**明确的否定边界**三者同时非空 | 只写"提升表达质量"，既不写产出形态，也不写不做什么 |
| **纯度** | `level` / `evidence_kind` | 落在四级之一，且含推断成分者必须标推断级 | 同一材料既写"官方文档支持"又写"根据表现推测"，两级混标 |
| **血统** | `source` / `license` / `contagion_class` / `hash_chain` | 来源可指到具体条目、许可可判定、传染性已判级、哈希链首尾可验 | 许可写"网上找的"、传染性留空、哈希链只有末节 |
| **毒性** | `blast_radius` / `irreversible_point` / `degradation_path` / `level` | 影响半径有界、不可逆点显式（可为"无"）、**降级路径非空** | 只写"影响较小"，不写不可逆点与降级路径 |
| **耗能** | `compute` / `storage` / `external_calls` / `attention_quota` | 四项各有量或显式"零"；**注意力打扰配额显式** | 算力写"很低"、注意力配额不写（等于无上限打扰） |
| **节律** | `plug_state` / `depends_on` / `depended_by` / `unload_cost` | 态已声明、依赖双向显式（可为 `[]`）、卸载成本给出 | 依赖留空导致挂载时才发现循环；卸载成本写"无" |

一个合格基因组的完整示例（六条齐全、全部可判定）：

- 表型：做"把外部材料压成结构描述"；产出"结构描述卡"；不做"保留原文、不做逐句改写、不做翻译替代"。
- 纯度：公开语料级，证据形态"可公开检索到原始出处"。
- 血统：来源指到具体条目、许可 MIT、传染性 none、哈希链两节点。
- 毒性：影响半径"单亚学科槽位"、不可逆点"无"、降级路径"回备用路径 p2"、级 green。
- 耗能：算力 0、存储 0、外部调用 0、注意力配额"每会话 ≤1 次提示"。
- 节律：呼吸态、依赖 `[]`、被依赖 `[t1]`、卸载成本"低（即时中止）"。

它保护了哪条公理：表型与毒性服务 P2（否定边界与降级路径是回滚的前提），纯度与血统服务 P3，
耗能与节律服务 P1（打扰是向用户索取资源）。

### 4.1 纯度四级与可进入区域

| 级 | 代码 | 秩 | 可进入区域 | 附加要求 |
|---|---|---|---|---|
| 官方文档级 | official_doc | 0 | 主干 | 许可与条款可在原站点逐条核对 |
| 公开语料级 | public_corpus | 1 | 主干（须血统齐备 + 代际校验通过） | 原始出处可公开检索 |
| 行为推断级 | behavior_inferred | 2 | 隔离区 | 必须标注"由可观察行为反推" |
| 黑箱借用级 | black_box | 3 | 隔离区 / 外部位 | 必须标"借来的信念"；禁食态自动不可用 |

判据：秩 ≥2 一律不得进主干；秩 3 不得出现在主干表述中。

## 5. 三态节律规范

| 态 | 定义（改什么） | 生效边界 | 回滚方式 | 成本 | 典型示例 |
|---|---|---|---|---|---|
| 呼吸态（热） | 策略、倾向、表达模板、阈值、探针节奏 | tick 边界 | 即时中止，无需快照 | 极低 | 探针间隔 5 拍→3 拍；模板权重 ×0.8；阈值 0.6→0.55 |
| 循环态（温） | 通路、规则集版本、路由表 | 心跳屏障边界（一次对齐后生效） | 回滚到上一屏障快照 | 中 | 经络新增一条语义通路；规则集 v3→v4；降级路由改指向备用路径 |
| 代谢态（冷） | 骨架、索引、基线、长期权重、主干槽位 | checkpoint 边界 | 冻结快照 + 回归验证通过后生效；回滚需重新校验 | 高 | 主干槽位重排；赫布基线重建；引入新数据源 |

设立循环态的理由：避免"半新半旧"的混合语义。判据：任何变化若同时触及两条以上通路，
即使每条通路各自只改阈值，也按循环态处理。

### 5.1 四问定态（优先级 Q1 > Q2 > Q3 > Q4）

| 问 | 内容 | 命中结论 |
|---|---|---|
| Q1 | 是否触碰矩阵主干槽位、节点分配、亚学科结构？ | 代谢态 |
| Q2 | 是否改写赫布权重基线或长期记忆结构？ | 代谢态 |
| Q3 | 是否跨越信任边界（外部能力/外部平台/新许可环境）？ | 至少循环态；引入新数据源则代谢态 |
| Q4 | 是否只改策略、表达、探针、路由、阈值？ | 呼吸态；但"只改路由表"归循环态 |

**未命中任何一问时默认取循环态，不得默认呼吸态**——默认更保守，是 P2 的直接推论。
直觉规则与四问一致：只读观察归呼吸，改写骨架归代谢，跨信任边界至少归循环。

它保护了哪条公理：P2（越深的变化越要求更强的锚点；默认取更保守态）。

### 5.2 判据与示例清单

| 变化 | 命中 | 定态 | 为什么不是更低一态 |
|---|---|---|---|
| 探针采样间隔 5→3 拍 | Q4 | 呼吸 | 只改节奏，无结构变化 |
| 表达模板权重 0.5→0.4 | Q4 | 呼吸 | 只改权重数值 |
| 新增一条语义通路 | Q4（路由） | 循环 | 路由改变会让上下游看到不同图 |
| 规则集版本 v3→v4 | Q4（规则） | 循环 | 半新半旧规则会同时生效 |
| 主槽位重排 | Q1 | 代谢 | 直接动骨架 |
| 赫布基线重建 | Q2 | 代谢 | 长期权重改变后旧快照不可解释 |
| 接入一个新数据源 | Q3 | 代谢 | 新来源意味着新血统与新污染面 |
| 接入已有审计的外部能力 | Q3 | 循环 | 信任边界变了但骨架未变 |
| 探针指纹基线重建 | — | 代谢 | 基线属长期结构（见 §7 感受器） |

## 6. 生命周期状态机

八阶段：候选 → 基因组校验 → 假饲 → 灰度 → 共生 → 观察 → 休眠 → 归档。

| 阶段 | 准入条件 | 产出物 | 可跳过性 | 失败处理 |
|---|---|---|---|---|
| 候选 | 有可描述的能力/知识提案 | 共生体提案（基因组初稿） | 不可跳过（入口） | 丢弃提案，不留账 |
| 基因组校验 | 六条染色体齐备 | 准入结论 + 缺失/不合格/否决清单 | 不可跳过 | 拒签并写拒签理由（可复现） |
| 假饲 | 校验通过 + 现行基线快照 | 假饲增益报告（同场对比、只算不生效） | **不可跳过** | 判"负/不足以判断"即退回候选，不得升灰度 |
| 灰度 | 假饲结论非负 + 已冻结回滚锚点 | 灰度记录（范围 + 锚点哈希） | 仅当"只读、不写状态、无外部调用"的呼吸态共生体可降为单会话灰度 | 立即中止并回锚点 |
| 共生 | 灰度完成 + 一键禁用可用 + 降级路径已声明 | 血统账本条目 + 注册表条目 | 不可跳过 | 撤销注册，回到休眠 |
| 观察 | 已共生 + 三类指标采样点已定义 | 有效性/耗能/免疫 三张采样表 | **不可跳过**（至少 64 拍） | 触熔断则进休眠，并把熔断原因写账 |
| 休眠 | 熔断或用户关闭 | 休眠记录（备用路径、协作边冻结、脏状态清单） | 仅"从未共生过"的候选可跳过，直接归档为拒签 | 备用路径不可用即断头路：禁止休眠，先修通路 |
| 归档 | 休眠完成，或拒签需留档 | 可复现包（配置/血统/效果报告/重建引用/哈希） | 不可跳过 | 缺件只能标"归档未完成" |

假饲不可跳过的理由（写入设计，不得删改）：跨域共振、反标签、表达注入类能力的效果天然延迟，
且极易被叙事美化。必须用同场对比证据替代"感觉变好了"。

它保护了哪条公理：假饲与灰度服务 P1（用证据替代替用户下判断），休眠与归档服务 P2 与 P3。

## 7. 三层授权与默认值

| 层 | 周期 | 决策粒度 | 默认值 | 用户动作 |
|---|---|---|---|---|
| 基因层 | 季度级 | 装哪一类共生体（族级），塑造人格倾向 | 不新增类别（关闭） | 显式选择族类并写进基因档案 |
| 内分泌层 | 周级 | 装多强、多久一次（剂量与频率），塑造性格强度 | 最低剂量 / 关闭 | 显式调整剂量频率，可回撤最低档 |
| 反射层 | 会话级 | 这一次会话怎么算，结束即回收，不留默认值 | 关闭（每次显式开） | 本会话显式授权，会话结束自动回收 |

### 7.1 fail-closed 细则（逐条可判）

| 编号 | 规则 | 违规判据 |
|---|---|---|
| FC1 | 新共生体默认关闭 | `new_symbiote_default` 不是"关闭"即违规 |
| FC2 | 毒性红者需二次确认并明示不可逆点 | 红级缺二次确认或缺不可逆点声明即违规 |
| FC3 | 高风险动作默认单次授权，不提供"记住我的选择" | 存在"记住选择"能力即违规 |
| FC4 | 自动放宽权限必须显式开启且可一键回到保守基线 | 自动放宽开启而无一键回保守基线即违规 |
| FC5 | 必须提供禁食态，黑箱借用类自动不可用 | 缺禁食态即违规；禁食态下黑箱类仍可用亦为违规 |

### 7.2 禁食态行为表

| 场景 | 必须行为 | 判定 |
|---|---|---|
| 断网启动 | 仅运行自有骨架，进程可正常起 | 起不来即违规（拒绝"先连一下"） |
| 黑箱借用类共生体 | 自动不可用，并在状态里标明原因 | 仍可用即违规 |
| 外部知识源 | 只读本地归档副本 | 尝试外部读取即违规 |
| 已是共生状态的呼吸态策略 | 可继续生效（不依赖外部） | 若该策略依赖外部则必须一并停用 |
| 恢复联网 | 不自动恢复被禁食禁用的共生体，需用户再次显式开启 | 自动恢复即违规（P1） |

它保护了哪条公理：三层授权整体服务 P1；FC4 与禁食态同时服务 P2（随时可退回保守基线）。

## 8. 消化道与血统治理

### 8.1 双通道

| 通道 | 可读 | 可产出 | 禁产出 |
|---|---|---|---|
| 解构通道 | 原始材料（只读） | 结构化中间表示（关系、层级、依赖） | 原文片段、逐句改写、引文译文 |
| 建构通道 | 结构化中间表示 | 用系统自有术语的重述 | 原始材料（含所谓"去标识摘录"） |

两通道之间只传递结构化中间表示；中间表示字段固定为：实体、关系、层级、依赖、缺口、血统哈希、
是否携带原文（必须为否）。判据：中间表示中出现任何原文片段，或携带原文标志为真，即违规。

默认产出形态为结构性蒸馏：只保留骨架与关系，不携带原文。

它保护了哪条公理：P3（可溯源靠结构 + 哈希，不靠原文搬运）。

### 8.2 概念传染性判定与隔离区

| 传染性等级 | 判据 | 处置 |
|---|---|---|
| none | 不强制改写下游表述 | 可进主干 |
| local | 只改自身领域的下游表述 | 可进主干，但必须带标注，且标注向下游传播 |
| downstream | 跨域强制改写下游表述 | 进隔离区；能力可用，术语不得出现在主干 |

判据：一个框架若在进入后使下游若干术语的定义发生变化，即为传染；跨域即 downstream。

它保护了哪条公理：P3（口径漂移必须被标注，否则血统失真）。

### 8.3 血统账本与哈希链

账本条目字段：共生体标识、来源、许可、纯度、改写者列表、代际、上一节点哈希、本节点载荷哈希、
本节点链哈希。

链规则（可判定）：

1. 载荷哈希 = 对本节点除"链哈希/载荷哈希/上一节点哈希"之外全部字段的规范化摘要。
2. 链哈希 = 对"上一节点链哈希 + 本节点载荷哈希"取摘要。
3. 校验：每节点上一节点哈希必须等于前一节点链哈希；链哈希必须能按规则 2 重算一致。
4. 任一节点不符即断链，断链处必须给出位置，且整链判为不可信。

写账时点：挂载、降级、休眠、归档四处，一处不漏；漏写即视为血统断链。

它保护了哪条公理：P3。

## 9. 信任半径与借来信念标注

外部能力登记必填三项：能看什么（读范围）、能返回什么（返回范围）、出问题退到哪里（降级路径）。
缺任一项不得挂载。调用全程记录输入与输出哈希。

标注规则：

| 情形 | 标注 | 判定 |
|---|---|---|
| 结论只依赖自有骨架推导 | 自有骨架推导 | 无外部依赖 |
| 结论任一依赖未通过审计 | **借来的信念（依赖不可审计：…）** | 逐条列出不可审计依赖标识 |
| 结论依赖不可审计但已声明降级路径 | 借来的信念 + 已声明降级 | 两者同时标，缺一即违规 |

借来信念占比 = 依赖不可审计的结论数 ÷ 结论总数；默认上限 0.20。
该指标持续上升意味着"自有推导"在萎缩，须在基因层讨论是否收紧外部依赖。

它保护了哪条公理：P3（外包得来的信念必须被标注为外包）。

| 机制 | METAB 可用 | 必须遵守 | 违规判据 |

## 11. 组合治理规则

| 关系 | 语义 | 判据 |
|---|---|---|
| 依赖 | 甲生效需乙已在场 | 乙不在组合内即组合无效 |
| 互斥 | 甲与乙不得同时生效 | 同时出现即组合无效 |
| 放大 | 两者叠加后爆炸半径大于各自之和 | 必须整体评审，逐条放行无效 |

白名单机制：

1. 以类别为单位登记允许配对；种子白名单四对：探针×策略、探针×模板、策略×模板、模板×外部知识源。
2. 白名单外的配对默认不生效（不是"待审核"，而是"不生效"）。
3. 白名单变更属循环态（规则集版本）；新增共生体节点本身仍属代谢态（见 K7）。
4. 高风险组合（含放大关系、纯度秩 ≥2、或毒性红）必须整体评审通过才生效。
5. 具传染性的共生体进入组合时，其标注口径自动向下游传播，下游不得省略标注。

它保护了哪条公理：P2（组合的爆炸半径不是单体之和）。

## 12. 度量指标与验收红线

| 维度 | 指标 | 门禁 |
|---|---|---|
| 有效性 | 假饲对比增益、探针指纹变化、任务成功率 | 增益 ≥ 0.05 且成功率 ≥ 0.90 |
| 耗能 | 算力、存储、外部调用、注意力打扰次数 | 四项须有值；打扰次数须落在基因组的打扰配额内 |
| 免疫 | 拦截数、越界尝试数、熔断次数、不可逆事件数 | 不可逆事件数 = 0（恒零，不接受"接近零"） |
| 韧性 | 回滚成功率、休眠后残留脏状态数、强制移除后核心可用率 | 残留 = 0 且核心可用率 ≥ 0.99 |
| 主权 | 用户主动开关比例、默认开启项数、禁食态可用功能占比、借来信念占比 | 默认开启项数逐版本下降；禁食态覆盖 > 0；借来信念占比 ≤ 0.20 |

阈值口径说明：上述数值是**本包的默认门禁**，不是普适真理；改动属基因层变更，必须在基因档案里
留痕，不得在会话内悄悄漂移。

验收红线（四条，无例外）：

| 编号 | 红线 | 后果 |
|---|---|---|
| R1 | 无假饲数据 | 不得挂载，无论创意多好 |
| R2 | 无降级路径 | 不得挂载 |
| R3 | 无法一键禁用 | 不得挂载 |
| R4 | 无血统 | 不得进入主干 |

综合判定：命中任一红线 → 拒；无红线但门禁未过 → 有条件通过（须补齐后才能共生）；全过 → 通过。

它保护了哪条公理：五维指标分别对应 P1（主权维度）、P2（韧性与免疫）、P3（借来信念）；
红线四条是三条公理的最小可执行交集。

## 13. 反模式清单与自检表

| 编号 | 反模式 | 自检问题 | 命中即 |

## 14. 分期落地路线

| 期 | 目标 | 范围 | 完成判据 |
|---|---|---|---|
| **一期 · 立宪** | 让 METAB 通道成为唯一入口，先把判定语言统一 | 公理与术语、六条染色体规范、纯度四级、三态定义、四条红线、七条反模式、fail-closed 五条 | 六条染色体校验与四问定态可对任一提案给出可判定结论；红线与反模式自检可运行；不落任何执行面 |
