# V21 · 概念解剖器 · 图像增强版使用手册

> 配套：`docs/V21_概念解剖器_图像增强_规划.md`（规划与验收）｜ 批次：V21（2026-11-04）
> 一句话：V20 教会概念解剖器"说人话"，V21 教会它"画像样的图"——既能本地画出爆炸图/标注图，也能把解剖结果锻造成 AI 生图提示词。

---

## 一、概念解剖器现在能做什么（一段话）

概念解剖器 = HoloAeon 的"汉字字典 + 画图工坊"。看到"经络""赫布场""城邦"看不懂时：

1. **说人话**（V20）：`--explain` 用大白话告诉你这是哪个模块、由哪些零件组成、怎么验证。
2. **画像样的图**（V21）：`--img explosion` 本地画出零件爆炸图（展开+编号+成品对照）；`--img annotated` 画标注图（引线+放大细节）。
3. **锻造成 AI 提示词**（V21）：`--forge` 把解剖真值锻造成八步提示词流水线（文字→搜索→初级图像描述→系统提示词→矩阵变体→优化→蓝图/美术/艺术化），拿提示词可交给 AI 出更精的图。

**确定性底线**：本地渲染永远可用、可复现（纯标准库零依赖）；AI 生图是可选增强，不影响解剖器任何原有输出。

## 二、三个落地场景

| 场景 | 谁用 | 命令 | 产出 |
|------|------|------|------|
| 汇报/PPT 要图 | 任何人 | `python -m holoaeon.concept_anatomy 经络 --img explosion --save jingluo.svg` | 像样的爆炸图 SVG（零件展开+编号+成品对照） |
| 文档插图 | 文档作者 | `python -m holoaeon.concept_anatomy 圆珠笔 --img annotated --save pen.svg` | 标注图 SVG（横截面+引线+放大细节） |
| 喂给 AI 出精图 | 视觉创作者 | `python -m holoaeon.concept_anatomy 圆珠笔 --forge` | 八步 JSON（含蓝图化/美术化/艺术化三档提示词） |

## 三、命令速查

```bash
# 本地确定性渲染（4 种风格）
python -m holoaeon.concept_anatomy 经络 --img explosion --save out.svg   # 爆炸图：展开+编号+成品对照
python -m holoaeon.concept_anatomy 经络 --img annotated --save out.svg   # 标注图：横截面+引线+放大细节
python -m holoaeon.concept_anatomy 经络 --img legend --save out.svg      # 图例图：色语义+零件清单
python -m holoaeon.concept_anatomy 经络 --img diagram --save out.svg     # 结构图：等距投影增强

# 直接看渲染器清单 / 独立 CLI
python -m holoaeon.concept_anatomy_render                         # 列 4 渲染器
python -m holoaeon.concept_anatomy_render 经络 --style explosion --save out.svg

# 视觉锻造台（八步流水线 JSON）
python -m holoaeon.concept_anatomy 圆珠笔 --forge
python -m holoaeon.concept_visual_forge 经络

# V20 兜底：说人话
python -m holoaeon.concept_anatomy 经络 --explain
```

**说明**：
- `--img` 未注册风格自动回落 diagram（容错协议）。
- 调色板三档：工业蓝（默认）/ 线稿黑白 / 全息四色；爆炸轴 vertical（默认）/ horizontal；`img_annotate`（编号开关）/ `img_compare`（成品对照开关）。
- SVG 为文本文件，浏览器/编辑器打开即可渲染。

## 四、渲染器系列（加载协议）

| 渲染器 | 协议名 | 画什么 |
|--------|--------|--------|
| 爆炸图 | `explosion` | 零件沿中轴展开 + 数字编号引线 + 底部成品对照区 |
| 标注图 | `annotated` | 主体横截面 + 引线文字标注 + 关键部位放大细节框 |
| 图例图 | `legend` | 维度色语义图例 + 零件清单 + 机制说明 |
| 结构图 | `diagram` | 等距投影增强版（30° + 序号） |

注册协议：`register_render(name, fn, desc)` / `load_render(name)`（未注册回落 diagram）——与扩展包机制同构，可旁挂自定义渲染器，不进维度。

## 五、视觉锻造台（八步流水线）

| 步 | 函数 | 干什么 |
|----|------|--------|
| 1 文字 | `forge()` | 接收任意概念文字 |
| 2 搜索 | `text_search()` | 内置概念命中；表外概念关键词抽取+就近概念 |
| 3 初级描述 | `image_desc_v1()` | 主体+关键元素+布局 |
| 4 系统提示词 | `system_prompt_gen()` | 风格/构图/色调模板 |
| 5 矩阵修改 | `matrix_modify()` | 6 风格×3 构图×3 色调变体 |
| 6 优化 | `optimize_prompt()` | 质量锚点+负面提示词+确定性锚点（只画映射表内元素） |
| 7-9 三档风格化 | `stylize()` | blueprint 蓝图化 / art_direction 美术化 / artistic 艺术化 |

风格矩阵：**风格** 工业蓝图/手绘线稿/水彩/赛博霓虹/极简几何/油画 × **构图** 爆炸分解/横截面/场景陈列 × **色调** 冷灰蓝/暖米白/高对比黑金。

工程路径思路：解剖器负责真值（不编造）→ 锻造台负责视觉翻译（规则化）→ 本地 SVG（确定性）或 AI 生图（生成式）双轨。**优化→创建→升级**：每批优化输出路径，新能力只旁挂不破维度。
