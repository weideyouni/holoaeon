## 1. 它是什么，不是什么

**是**：一套把"设计评审"做成可复算流程的旁挂引擎。命令（词汇）→ 确定性规则（判据）→ 分级（P0–P3）→ 四通道分流（经络）→ 共现权重（赫布）→ 三编译模式（EDA 三段式）。

**不是**：

- 不是 Impeccable 的分支或移植：本仓没有它的引擎二进制、没有它的 62 条规则文本、没有它的 `PRODUCT.md` / `DESIGN.md` 模板。
- 不是 LLM 评审：全部判定由正则与结构扫描给出，**零 LLM、零 API key、零出网**。
- 不是自动改码器：只输出命中、分级与先修顺序，**不写回你的源码**（是否改、改哪句，归人）。
- 不改产出维度：**25 智能体 / 47 技能 / 9 域包** 不动，`data/extension_slots.json` 仍是 **12 条**，本能力不认领也不占用任何 `EXT-` 卡槽。

## 2. 三分钟上手（按流程使用）

在仓库根目录执行，无需安装任何依赖：

```powershell
# 一条命令跑完 8 项判据，并写 reports/design_vocab_check.json
python scripts\verify_design_vocab.py

# 只看结果
python -c "import json;d=json.load(open('reports/design_vocab_check.json',encoding='utf-8'));print(d['verdict'],d['passed'],'/',d['total'],d['facts'])"
```

在代码里调用：

```python
from holoaeon.design_vocab import scan, rank, simulate, compile_text, route, cooccurrence

hits = scan(open("page.html", encoding="utf-8").read())   # 全部命中，按规则 id 排序
ranked = rank(hits)                                       # P0 → P3，直接就是先修清单
report = simulate(text)                                   # verdict=PASS/WARN/FAIL + first_fix
full = compile_text(text)                                 # elaborate / simulate / netlist 三段
channel = route(hits)                                     # 四通道分流 + 最堵通道
weights = cooccurrence([rules_of(doc) for doc in docs])    # 跨页面共现权重
```

判读口径：`verdict=FAIL` 表示出现 **P0**（如正文小于 12px，属可读性硬伤）；`WARN` 表示只有 P1–P3；`PASS` 表示零命中。`first_fix` 就是该先动的那一条。

## 4. 12 条确定性规则（判据层）

本仓自写，**不宣称与上游 62 条等量**。每条规则一个 id、一个分级、一个经络通道，命中给出行号与片段证据，同行同输入必得同输出。

| 规则 | 名称 | 分级 | 通道 | 判据（一句话） |
|---|---|---|---|---|
| DV-01 | overused-font | P1 | qi | `font-family` 直接顶 `Inter`（不走变量） |
| DV-02 | purple-gradient | P1 | qi | 渐变里出现紫 / 靛系色值 |
| DV-03 | nested-card | P2 | blood | `class` 含 `card` 的 `div` 嵌套 ≥2 层 |
| DV-04 | tiny-text | **P0** | shen | 字号 < 12px |
| DV-05 | heading-skip | P1 | shen | 标题跳级（如 h1 → h3） |
| DV-06 | shouting-caps | P2 | qi | 连续大写 ≥32 字符当正文 |
| DV-07 | shadow-stack | P3 | lymph | 单条 `box-shadow` ≥3 段 |
| DV-08 | emoji-ui | P3 | shen | 标题里塞 emoji |
| DV-09 | placeholder-copy | P1 | lymph | 出现 `lorem ipsum` 占位文案 |
| DV-10 | inline-style-soup | P2 | lymph | 单元素行内声明 ≥4 条 |
| DV-11 | gradient-text | P3 | qi | `background-clip:text` 配渐变文字 |
| DV-12 | pill-everywhere | P3 | blood | `border-radius` 999/9999/50% 出现 ≥3 处 |

扩展一条规则要动三处且必须同时改：`detectors._rule_table()`（id/名/级/通道）、`detectors.scan()`（判定）、`meridian.RULE_CHANNEL`（分流）；然后补 `verify_design_vocab.py` 的脏样本与 `test_design_vocab.py` 的断言。**规则数变了，注册表 `local.rules` 也要跟着改**，否则 D3 直接红。

## 5. 三种编译模式（EDA / VHDL 对照）

把界面源码当电路来处理，三段各自可单独复核，也可串成一次完整"编译"：

| 模式 | 动作 | 输出 | EDA / VHDL 对应 |
|---|---|---|---|
| `elaborate` | 展开标签与属性 / 样式声明 | 元件数、端口数、元件种类 | elaboration / 网表展开 |
| `simulate` | 跑 12 条规则 | 命中数、分级分布、`verdict`、`first_fix` | testbench 跑波形 |
| `netlist` | 命中收敛为"规则 → 通道"边 | 节点数、边数、边权（命中次数） | 综合 / 网表 |

`compile_text()` 一次返回三段；`netlist` 的边权就是同一规则在同一文档里的命中次数，可手算核对——这保证"编译结果"不是黑箱。

**数字分身矩阵**在本批的落法：`elaborate` 出"元件 × 端口"的二维面，`netlist` 出"规则 × 通道"的二维面，`hebbian.cooccurrence` 出"规则 × 规则"的共现面；三面同源、可交叉验算，而不是另起一套不可复核的画像。

## 6. 六机制融合说明（本批新增的接线，不新增维度）

| 机制 | 在本批的落点 | 与既有链条的关系 |
|---|---|---|
| 全息心跳 | `verify_design_vocab.py` 一次 8 判据即一次心跳；`reports/design_vocab_check.json` 是可回读的心跳记录 | 沿用 `reports/*_check.json` 的出票习惯，不改既有心跳节律 |
| 细胞骨架 | `elaborate` 的元件 / 端口计数，是"结构骨架"的可复核度量 | 与 `fusion_upgrade/hebbian_store.py` 的图结构同构，不另建存储 |
| 语义通信底座 | `vocabulary.py` 的 24 命令即"设计语义总线"；命令 id 可直接做路由键 | 与 `semantic_family.py` 平行的第二语义族，**不合并族号、不动 47** |
| 皮肤机制 | 分级 P0–P3 + 四通道分流，是"皮肤层"的呈现规则；只出建议不改人 | 与 `guard_layers/` 的守卫分层互补，不替代其红线 |
| 赫布协作场 | `hebbian.py`：共现 → 归一无量纲 → 余弦相似；反复同现即成组 | 与 `hebbian_store.py` 同一思想，本批只做只读计算，不落持久权重 |
| 经络机制 | `meridian.py`：四通道 `blood / lymph / qi / shen` 分流，给"先通哪条脉" | 通道口径沿用仓内既有四组，不新增第五通道 |

**runtime → graph 的有机融合**：`scan` 是 runtime（逐行扫），`netlist` 是 graph（规则-通道边），`cooccurrence` 是跨文档的 graph 聚合；三者共用同一份规则表，因此不会出现"运行时命中一套、图上又是另一套"的漂移。

**自组织相似性**：不给阈值、不预设簇。相似度只由共现权重算出（同一批文档里总是同时出现的两条规则，余弦自然趋近 1），新增文档即可重算，权重不封存成配置。

## 8. 合作开发：怎么加东西而不踩锁

1. **先看锁**：任何"新能力"先答一句——它会不会让 25/47/9 变化？会，就停；不会，才继续。
2. **优先旁挂**：加子包、加 `scripts/` 判据、加 `docs/` 指南，别往 `skill_matrix` 里塞条目，别往 `extension_slots.json` 里加槽（该文件条数被 `test_v5` 硬断言为 12）。
3. **规则成对交付**：一条规则 = 判定 + 分级 + 通道 + 脏/净样本断言，四件齐了才算完成；只写判定不写样本，等于没验。
4. **写序不越位**：改完先跑 `verify_design_vocab`，再跑 `tests_contract`，再按 G9 写序（`verify_v44` 两次 → v45/v46/v5 → `build_b9_closeout` → `build_b8_dual_sync` → `build_b9_zip` → `five_site_dna build` → `verify`/`preflight`）。
5. **出网留空**：包内禁止 `subprocess` / `urllib` / `requests` / `socket` / `http`，需要跑外部 CLI 一律放 `scripts/`；本批没有任何外部 CLI 依赖。
6. **许可留痕**：引用上游范式时写清作者与 Apache-2.0；**不 vendor、不复制**，就不必在仓内放它的 `LICENSE` / `NOTICE`，但声明必须可查（见注册表 `source`）。
