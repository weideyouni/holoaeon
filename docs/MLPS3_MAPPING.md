## 一、安全计算环境（GB/T 22239-2019 三级 · 9 类控制点）

| 控制点 | 状态 | 仓内证据 / 责任边界 |
|---|---|---|
| 身份鉴别 | 已对齐（对接） | `phc_chronic_engine.MLPS3.CHECKLIST["身份鉴别"]`：口令复杂度+失败锁定，对接机构统一认证；`forge_gate.ModelSplitRules` 的 `explicit_auth` 授权门；`path_write_authorized` 写授权标记 |
| 访问控制 | 已对齐 | RBAC Editor/Viewer 最小权限（tcm-meridian-kb 先例）；`permissions` 字段逐任务声明；L9 路径闸门（`guard.py`） |
| 安全审计 | 已对齐 | append-only 审计日志+逐行 SHA256 链（`MLPS3.audit`/`AuditTrail`/`SyncLedger`）；`craft_gate.EvidenceLedger` 证据台账 |
| 入侵防范 | 天然不适用（大半） | 核心包零网络（网络模块 import 0 处）→ 远程入侵面结构性不存在；`NetDiode` 出站白名单=空集消除 C2 回连路径；最小安装原则=零依赖 19MB |
| 恶意代码防范 | 天然不适用（大半） | 纯标准库零第三方包 → PyPI 投毒面结构性不存在（OWASP Agentic ASI04 不适用）；`redline_scan.py` 禁 eval/exec/compile |
| 可信验证 | 已对齐 | 双冻结哈希（V1 规格黄金 + bench 实测）+ `check_sums.py` 复算闸 250 条 0 不匹配 + `SHA256SUMS` 全量清单 |
| 数据完整性 | 已对齐 | SHA256SUMS + 存档 SHA256 指针校验（`FeedEnvelope` 七模态信封零像素）+ `SyncLedger` 版本化同步台账 |
| 数据保密性 | 须运营主体补（主体） | 引擎留接口、密钥不出引擎；静态加密/传输加密由部署层负责（内网段 HTTPS 属部署侧） |
| 备份恢复 | 已对齐（机制）+须运营主体补（演练） | 五地同步台账（本地→Gitee→GitHub→HF→向量海）+ `archive_sync` SHA 校验入档；**灾备演练与恢复时效须运营主体执行** |

## 二、安全区域边界 / 安全通信网络（三级）

| 控制点 | 状态 | 说明 |
|---|---|---|
| 边界防护 / 访问控制 | **天然不适用** | 默认离线零网络 → 无网络边界可防护；`OUTBOUND_ALLOW=()` 为架构不变量（非可配置策略项） |
| 传输加密 / 完整性 | **天然不适用**（引擎态） | 引擎零网络连接；127.0.0.1 本地 HTTP 与内网段传输属部署侧配置 |
| 入侵检测 | 天然不适用 | 无外部通信信道；`local_model_probe` 仅本机端口探测（bridges 层） |

## 三、管理要求（全部须运营主体完成）

安全管理制度／管理机构／管理人员／建设管理／运维管理五项为**组织与流程要求**，
须由运营主体（医院信息科/网络安全负责人）建立并执行，开源项目侧无对应物。
日志留存 ≥6 个月须由部署方配置（引擎侧审计日志为 append-only JSONL，留存策略属部署侧）。

## 四、汇总口径

- **天然不适用**：约 1/3 控制点因离线架构无网络边界而不适用或高风险项归零——这是
  出站白名单=空集的结构性红利（V47-B 注记：不是可配置策略项）。
- **已对齐**：安全计算环境 9 类中的 6 类有代码级证据（上表第一列）。
- **须运营主体补**：数据保密性主体、备份演练、全部管理要求、**定级备案与年度测评**
  （责任单位=系统运营主体，测评机构=公安备案机构）。
