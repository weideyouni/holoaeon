# HoloAeon V4.4 · 接入真实模型配置指南

> 适用：`holoaeon/fusion_upgrade/model_gateway.py`（V4.4-B1 起）
> 口径：本仓**只拼请求、不发请求**；`evidence_class=simulated`；仿真 ≠ 证明；碳基终裁
> 密令：潮起开门，潮落闭嘴 / 好嘞玉安（等同签字）

---

## 一、这件事的边界（先看清再动手）

| 本仓做 | 本仓不做 |
|---|---|
| 登记 19 家 provider / 5 种协议族 / 4 个本地运行时 | 不代你发网络请求、不代你计费 |
| 按协议族把 `url + headers + body` 拼对 | 不保存、不读取任何密钥值（只认环境变量名） |
| 给出一套「默认全关 → 显式开启」的开关 | 不会因为装了目录就自动联网 |
| 未配置时给占位符与降级路径 | 不校验某家 key 是否有效（那需要真请求） |

**红线未动**：不接设备、不出剂量、不做诊断；医学问句仍先在 `guard` 拦，任何模型都拿不到剂量类请求。

## 二、三件套：BASE_URL / API_KEY / model

每家 provider 在目录里都有两个环境变量名：`*_BASE_URL`（可选，缺省用官方默认）与 `*_API_KEY`（必填，本地运行时可空）。
再加上一个**总开关** `HOLOAEON_REAL_MODELS=1`，三者凑齐才会把该后端注册进 `ModelAdapter`。

```powershell
# 1) 总开关（不开则全部 disabled，适配层只剩本地事实包）
$env:HOLOAEON_REAL_MODELS = "1"

# 2) 某个 provider 的地址与键（键只放环境变量，绝不写进仓库）
$env:HOLOAEON_DEEPSEEK_BASE_URL = "https://api.deepseek.com/v1"
$env:HOLOAEON_DEEPSEEK_API_KEY  = "<你的 key>"

# 3) 型号由你在调用时传，或写进自己的启动脚本
$model = "deepseek-chat"
```

`model` 不写死在本仓：目录里的 `models` 只是**代表性示例**，型号会随官方版本增删。运行时以你传入的 `model` 为准。

## 三、按协议族抄作业

### 3.1 OpenAI Chat Completions（最通用）

适用：OpenAI、DeepSeek、通义千问（DashScope 兼容模式）、豆包方舟、Kimi、GLM、MiniMax、文心千帆 v2、混元、阶跃、Grok、Mistral、OpenRouter、以及**所有本地运行时**。

```powershell
$env:HOLOAEON_OPENAI_BASE_URL = "https://api.openai.com/v1"
$env:HOLOAEON_OPENAI_API_KEY  = "<你的 key>"
```

拼出来的请求形状：`{"model": "<model>", "messages": [{"role":"user","content":"..."}], "stream": false}`。

> 兜底：只要你的网关说 OpenAI 形状（自建代理、公司内网网关、私有微调服务），直接用 `custom`：
> `HOLOAEON_CUSTOM_BASE_URL` + `HOLOAEON_CUSTOM_API_KEY` + 你的 `model`。

### 3.2 Anthropic Messages

```powershell
$env:HOLOAEON_ANTHROPIC_API_KEY = "<你的 key>"
```

形状差异：`system` 是**顶层字段**，不在 `messages` 里；必须带 `max_tokens`；鉴权头是 `x-api-key` + `anthropic-version`。

### 3.3 Google Gemini

```powershell
$env:HOLOAEON_GEMINI_API_KEY = "<你的 key>"
```

形状差异：`contents[].parts[].text`，URL 是 `.../models/<model>:generateContent`，鉴权头 `x-goog-api-key`。

### 3.4 AWS Bedrock Converse

```powershell
$env:HOLOAEON_BEDROCK_TOKEN = "<临时 token>"
```

形状差异：`messages[].content[].text` + `inferenceConfig`。正式环境用 IAM 签名，本仓只拼不签。

### 3.5 Azure OpenAI

```powershell
$env:HOLOAEON_AZURE_BASE_URL = "https://<resource>.openai.azure.com/openai/deployments/<deployment>"
$env:HOLOAEON_AZURE_API_KEY  = "<你的 key>"
```

形状差异：`deployment` 取代 `model`，且必须带 `?api-version=`；鉴权头是 `api-key` 而非 Bearer。

## 四、本地运行时（不花钱、不出网）

三家都暴露 OpenAI 兼容端点，`region=local` 时 `key_env` 允许为空：

| 运行时 | 默认 BASE_URL | 起服务 |
|---|---|---|
| Ollama | `http://localhost:11434/v1` | `ollama serve` |
| vLLM | `http://localhost:8000/v1` | `vllm serve <模型>`（另支持 Anthropic Messages 形状） |
| llama.cpp server | `http://localhost:8080/v1` | `llama-server -m <gguf>` |
| LM Studio | `http://localhost:1234/v1` | 桌面端开启本地服务 |

```powershell
$env:HOLOAEON_REAL_MODELS = "1"
$env:HOLOAEON_OLLAMA_BASE_URL = "http://localhost:11434/v1"
# 本地通常不需要 key；model 用 `ollama list` 里已有的名字
```

## 六、成本与额度（口径写清，不替你花钱）

- 目录里 `input_cost/output_cost` 一律 `0.0`：本仓**不内置价目表**（价格变动频繁，写死会误导）。要控成本，在 `ModelAdapter.route(..., max_cost=...)` 里传你自定的阈值。
- 本地运行时 `latency_ms=50`、云端 `800` 只是**排序用的经验值**，不是实测。
- 用量记账走 `ModelAdapter.record_usage()`（simulated），不产生真实账单。

## 七、失败与降级顺序

1. 某家 401/403：先确认 `*_API_KEY` 是否注入到**当前进程**（`$env:` 只活当前会话）。
2. 某家 404：多半是 `BASE_URL` 少了版本段（`/v1`、`/v2`、`/compatible-mode/v1`）或 Azure 少了 deployment。
3. 某家 400：对照第三节的「形状差异」逐字段核；`openai_chat` 的 body 最宽容。
4. 全都不通：落到本地运行时（Ollama / vLLM / llama.cpp / LM Studio）。
5. 本地也没有：落到 `custom` 指向你的内网网关；再没有就**保持默认关闭**，走事实包（`fact-pack-local`）——系统仍可用，只是没有真模型。

---

## 八、安全纪律

- 密钥只进环境变量，**永不入库**：`A5` 会扫 `sk-` 形态与 `key_env` 赋值形态。
- 不要把 key 写进 `README`、票据、回执；票据里只写「以命令回读为准」。
- 生产环境建议：临时 token + 最小权限 + 出网白名单；本仓不做凭证托管。
- 医学边界不变：不接设备、不出剂量、不做诊断；真模型接进来也不会改变 `guard` 的拦截顺序。
