## 一、开发者的第一性原始意图（本仓为什么长这样）

这套工程不是"堆功能"，而是被三条第一性原则约束出来的：

1. **可复算**：任何结论都必须能由一条命令重新算出来。所以每批都有 `verify_*.py`、每份回执都带 `sha256`、每个数都是"以命令回读为准"，不接受"我记得是 12 个"。
2. **不侵入**：新能力一律**旁挂**。25 智能体 / 47 技能 / 9 包这三个锁数从 B0 到 V4.6 一次没动；语义族从 19 扩到 100、插件从 0 到 6 项接推理，都是加文件而不是改结构。
3. **签字即门**：能改结构的人必须先签字。密令、实名、"未认领"三种状态在系统里是同一件事——**没有签字就没有启用**。

> 一句话：**先声明、再旁挂、后签名**。卡槽（slot）就是把这条原则写成可读文件。

## 三、卡槽清单（14 个，`data/extension_slots.json`）

卡槽分八类：`provider / protocol / dimension_shadow / evidence / plugin_hook / runtime / gate / doc_channel`。
状态四档：`open`（可认领）/ `reserved`（预留）/ `occupied`（已占）/ `blocked`（等拍板）。

### 已占（occupied）——已经真跑过，别重复造

- **EXT-PROTOCOL-01** embeddings 形状：真发 200 / 768 维，回执 `reports/v45_live_probe_emb.json`。
- **EXT-PROTOCOL-02** chat 形状：真发 200 / 41+29 tokens，回执 `reports/v45_live_probe.json`。
- **EXT-GATE-01** 五地同步门禁：G9 写序 + P1–P7 preflight，每批复用。
- **EXT-DOC-01** 飞书阅读入口：`.md → docx` 串行导入。

### 开放（open）——现在就能认领

- **EXT-PROVIDER-01** Ollama 本地运行时：契约是 OpenAI 兼容 `/api/chat` + `/api/embeddings`，默认关闭，base_url 必须指回环。认领后只需复跑探针，判据沿用 B1–B7。

### 预留（reserved）——位置留着，不预埋实现

- **EXT-PROVIDER-02** vLLM / TGI 自建推理。
- **EXT-PROTOCOL-03** OpenAI Responses / Anthropic Messages（新增形状，不覆盖已有）。
- **EXT-DIM-02** 康复域知识库 V5 影子槽（只读外挂，不改 25/47/9）。

- **EXT-RUNTIME-01** 端侧小模型（MiniCPM 级，只读推理）。

### 等拍板（blocked）——不是不能做，是没授权

- **EXT-DIM-01** 语义族 V2 影子槽：要你定 `family_id` 口径（另立身份声明 vs 改族本体）。
- **EXT-EVIDENCE-01** gap 卡证据等级上调：要你定是否允许人工逐篇核对后升 tier。

## 四、合作开发：五步认领法

1. **认领**：在票据里写 `slot_id` + 契约（改哪个文件、加什么判据、失败回滚点）。
2. **实现**：只加**旁挂文件**；不改锁数、不碰他人模块、不动 `model_gateway.plan` 已有形状。
3. **自检**：`v3_gate 32/32` + `unittest tests 34 OK` + `tests_contract` 全绿 + `redline_scan` 零违规。
4. **签字**：weideyouni / 潘荟丞 / 密令（潮起开门潮落闭嘴、好嘞玉安）任一，效用等同。
5. **出票**：`data/<批次>票据.md` + `reports/<批次>_check.json` + 五地同步 + README 追加一段。

> 认领了但没做完？把 status 留在 `reserved` 并写 `next_action`，**不要**把票写成已完成。

## 五、按流程使用：三条路，任选一条

**A. 只读验证（最安全）**
```
python scripts\verify_v44.py        # 19 家 provider + 5 协议形状
python scripts\verify_v45.py        # B1–B7 真实回环调用
python scripts\verify_v46.py        # C1–C9 卡槽与文档
```

**B. 本地真调（零成本、不出网）**
```
& "$env:USERPROFILE\.lmstudio\bin\lms.exe" server start
& "$env:USERPROFILE\.lmstudio\bin\lms.exe" load qwen2.5-0.5b-instruct --identifier qwen25 -y
python scripts\live_gateway_probe.py --model qwen25 --mode chat
```

**C. 接云端（要凭证 + 计费口径）**
只有在你明确给出某家 key 并接受计费后，才把 `HOLOAEON_REAL_MODELS=1` 与 `<PROVIDER>_API_KEY` 注入；
本仓**不预置价目表**，`input_cost/output_cost=0.0` 是占位不是免费。

## 七、出错了怎么办

| 现象 | 处置 |
|---|---|
| 五地 `drift` 非空 | 按 G9 顺序重跑：校验器 → 清单 → zip → 回执，迭代到 zip sha 不动点 |
| `tests_contract` 红在 `test_11_sums` | 说明改了文件没重建 `dual_repo_sums`，跑 `build_b8_dual_sync.py` |
| HF `mismatch` 非空 | 查是否中文路径被转义（必须 `-c core.quotepath=false`），再重推 |
| 向量海 `bad_sha256` | 先 copy 74 再 listdir，顺序反了就有自指 |
| 模型 `lms import` 报 `EPERM mkdir 'D:\'` | LM Studio 的 `downloadsFolder` 指到盘根了，改到 `C:\Users\Administrator\.lmstudio\models` 再 import |
