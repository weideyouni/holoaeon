## 一、这东西是干嘛的（一段话）

**概念解剖器 = HoloAeon 项目的"汉字字典"。**

你看到"经络""赫布场""城邦"这些词看不懂时，查一下，它用大白话告诉你：这个词是哪个模块、由哪些零件组成、怎么验证它在工作、去哪看源码。

一条命令，五秒搞定。

```powershell
python -m holoaeon.concept_anatomy 经络 --explain
```

## 二、三个真实落地场景

### 场景一：新人看代码，看不懂"经络"是什么

**谁用**：刚进项目的开发者、想读源码的贡献者

**怎么用**：

```powershell
python -m holoaeon.concept_anatomy 经络 --explain
```

**看到什么**：

```
经络（机制类概念）
══════════════════════════════════════════════════

一句话：自组织相似性类节点共振——相似记忆/节点通过关键词自动关联

靠什么实现：topology_resonance.resonance_node

由8个零件组成：
  1. resonance_node
  2. mandala_fanout
  3. mobius_edge
  4. klein_convergence
  5. kalman_state
  6. bayesian_guard
  7. hilbert_project
  8. dissipation_measure

怎么验证它在工作：同输入关键词→同共振结果集

去哪看源码：packs/topology_resonance_pack.py
```

**产出**：一段能直接读的大白话，新人立刻知道"经络 = 共振关联机制"，还知道去哪看源码。

### 场景二：改代码前，确认影响范围

**谁用**：要改某个模块的开发者

**怎么用**：先解剖相关概念，看它涉及哪些零件

**例子**：要改 `guard.py`，先查"皮肤机制"

```powershell
python -m holoaeon.concept_anatomy 皮肤机制 --explain
```

```

══════════════════════════════════════════════════

一句话：8层内置守卫+2层附加守卫，串联检查每个信封

靠什么实现：guard L1-L8 + L9(path_gate) + L10(bayesian)

由10个零件组成：
  1. L1_structure
  2. L2_size
  3. L3_danger
  4. L4_permission
  5. L5_unauthorized
  6. L6_metadata
  7. L7_audit
  8. L8_consistency
  9. L9_product_path
  10. L10_bayesian

怎么验证它在工作：信封→Verdict（同信封→同判定）

去哪看源码：guard.py
```

**产出**：动手前看清这个模块由哪些零件组成，改动会牵动哪些部分。

### 场景三：写文档 / 汇报 / 培训材料

**谁用**：写技术文档、写汇报、做培训材料的人

**怎么用**（在代码里取文字或结构化数据）：

```python
from holoaeon.concept_anatomy import explain

# 方式1：大白话文字，直接贴进文档
print(explain("去幻觉"))
```

```
去幻觉（验证类概念）
══════════════════════════════════════════════════

一句话：8阶段流水线：输入→Seb提取→现实锚点→快照向量→莱布尼茨比对→同义映射→判定→赫布更新

靠什么实现：dehallucination(Leibniz PSR + 张平Seb + 赫布场)

由8个零件组成：
  1. input
  2. seb_extract
  3. reality_anchor
  4. snapshot_vec
  5. leibniz_compare
  6. synonym_map
  7. verdict
  8. hebbian_update

怎么验证它在工作：同文本→同判定（确定性）

去哪看源码：dehallucination.py
```

**产出**：可直接贴进文档/汇报/培训材料的概念解释。

## 三、一条命令速查

| 我想干什么 | 命令 |
|-----------|------|
| 查"经络"是什么意思 | `python -m holoaeon.concept_anatomy 经络 --explain` |
| 查"皮肤机制"（改代码前） | `python -m holoaeon.concept_anatomy 皮肤机制 --explain` |
| 看全部可用概念 | `python -m holoaeon.concept_anatomy` |
| 拿结构化 JSON 数据（给程序用） | `python -m holoaeon.concept_anatomy 经络` |
| 在 Python 里取解释文字 | `from holoaeon.concept_anatomy import explain; print(explain("去幻觉"))` |

> 概念名要一字不差（中文）。写错会得到"不是内置概念 + 可用概念列表"提示，不会崩。

## 五、还能干什么（高级用法，可跳过）

- **拿结构化数据**（给程序/文档用）：`ConceptAnatomizer().anatomize("经络")` → JSON（含十步工序、组件、审计四检查）。
- **调输出**：26 个设计 Token 可覆盖，如 `ConceptAnatomizer({"rt_theme": "light"})`、`{"rt_html_enabled": True}`。
- **管家菜单**：`python -m holoaeon.butler_os` → 菜单 12 交互式解剖。
