## 四、自写回执（A10）的处置口径

- 判据：`reports/*.json` 从 `five_site_dna.REPO_FILES` 派生候选，产生者从 `scripts/{verify_,build_,check_,gen_}*.py` 回填文件名得到；派生为空时退回 `LEGACY_SELF_REPORTS` 并标 `self_derive="legacy"`（fail-loud，不静默）。
- 排除范围：**只排除 `changed` / `new`**；`missing` 不排除——删回执是真实退化，必须判红。
- 差分证据：每条被排除项记录 `owner` + `prev_sha16` + `curr_sha16`，回执被意外改写仍留痕，只是不再单独判红（该职责由该回执的 owner 校验器自身承担）。
- **新增写型校验器时无需改 A10**：只要它写的是 `reports/*.json` 且脚本名以 `verify_/build_/check_/gen_` 开头，下次跑 A10 自动纳入。
- **A10 比的是全仓漂移，不只 `reports/`**：改 `README.md` / `docs/*` 后直接跑 `verify_v44`，会报 `repo:changed:<doc>` 并判红（V6.1-B3 实测）。正确顺序是**先 `five_site_dna build` 再跑 v44**；这是 `build` 必须排在写型校验器之前、而 `build` 又要以最新文档为输入的时序含义。

## 五、五地同步（同对象同 hash）

| 站 | 动作 | 回读方式 |
|---|---|---|
| S1 本地 | `git commit` | `git rev-parse HEAD` |
| S2 Gitee（权威） | `git push https://oauth2:<token>@gitee.com/<owner>/holoaeon.git HEAD:main`（令牌必须作密码、`oauth2` 作用户名；裸拼用户名位会认证失败。脱敏用 `$_.ToString() -replace $tk,"***"`，勿用 `.Replace`——stderr 为 ErrorRecord 时抛异常吞真实错误） | `git ls-remote https://oauth2:<token>@gitee.com/<owner>/holoaeon.git refs/heads/main`，延时 12–20 s |
| S3 GitHub | `git push origin HEAD:main` | `git ls-remote`，延时 12–20 s |
| S4 向量海 | 新增号段 → copy `SHA256SUMS` 到 `74_SHA256SUMS` → `build_vector_sea_manifest.py --dir <S4>` | `check()` → `PASS` + `sums_74_in_sync=True` + `bad_sha256=[]` |
| S5 HF | `python scripts\mirror_hf.py --base <旧短sha> --head <新短sha>` | `sha` + `remote_files` + `mismatch=[]` |

**顺序铁律**：向量海必须「换号段 → 换 74 → 建 manifest」，颠倒会让 `74_SHA256SUMS` 自指 `bad_sha256`；建 manifest 必须用 `build_vector_sea_manifest.py`，手写 `listdir` 版本会漏哈希。

**回执**：`_holoaeon_v4_five_site_receipt_20261102.json` + `_receipts\..._<批次>.json` 副本，字节相同；回执**不入 git**。刷新范式：`dict(old)` 铺底 + `update`；`files` 取自向量海 `manifest.json`；`history` 过滤用 `isinstance(h, dict)` 守卫。

**体检判定口径（批1 固化，脚本即纪律）**：
- 五分类含义：✅=自检全绿（含慢启动复核）；⚠️=真缺口（失败计数>0 或输出全绿但 exit≠0）；📄=无代码入口；❌=有 py 但无 selftest/main 入口；⏭=镜像/临时/归档/宿主复制品。
- 防误报三则：①失败判定认「失败 N / N 组失败 / FAILED: N / [FAIL] / json failures>0 中 N>0」才计失败（防「失败 0 组」误伤）；②输出识别兼容 JSON（`"ok":true` / `"failures":0` / `ALL PASS` / `全部通过`）；③首轮 30s 超时后用 `TIMEOUT_LONG=240s` 慢启动复核一次（长自检不再误判卡死）。
- 入口探测：selftest 系优先（selftest.py/selfcheck.py/selftest_runtime.py/tests_lite.py 等），其次 main 系，再 runtime/tests 子目录，最后包级 `__main__.py`（走 `python -m`）；包级相对导入失败自动 fallback `python -m <子包>.selftest`。
- 人工复核：脚本判定为 ⚠️/❌ 的目录须人工拉 tail 复核，误报改判并在 JSON 标 `verified:"human"`；**红线全程只读、缺依赖只记录不 pip install、不改目标文件、医学内容零剂量不诊疗**。
- 对照表报告命名：`F:\doubaowork\HOLOAEON_全仓runtime体检对照表_<日期>.md`（含五分类聚合、分域适配优先级、大词与实物落差、红线发现）。

## 九、V11 批次实测备注与修正（2026-11-03 实测固化）

> V11 城邦架构融合批（`2c9a394 → bc38b70 → 99f27d4 → 55b42ad → 2714b80`）推送与五地收口期间实测。以下均已在当批验证，作为 §五/§六 的补充口径。

1. **Gitee 认证方式（本轮最大修正）**：Gitee 私有令牌 URL 必须 `https://oauth2:<token>@gitee.com/…`。裸拼 `<token>@` 时 `git push` 报 `Incorrect username or password`（exit 128）；**ls-remote 通 ≠ push 通**（公开仓匿名可读、写仍要认证）。历史批次"Gitee 卡死"实为认证失败被脱敏管道吞错，根因见 §六 新行。
2. **脱敏管道**：`ForEach-Object { $_.Replace($tk,"***") }` 在 stderr 为 `ErrorRecord` 时抛异常、吞掉真实错误。统一改 `$_.ToString() -replace $tk,"***"`；先看 `$LASTEXITCODE` 再判断是否重试。
3. **GitHub 外部回退源**：当批 5 次观察 `push` 显示成功但数分钟内 main 被 forced 回退到旧基线（fetch 证据：`+ <新>...<旧> main -> origin/main (forced update)`）。HoloAeon 相关 cron 经核实均只读不 push，回退源未查出。处置：重推 + **立即 fetch**（传输级验证，比 ls-remote 权威）回读 `git rev-parse origin/main`；交付凡涉远端 sha 一律「以命令回读为准」；不无限重推（外部竞争写源存在时重推无收益）。
4. **HF 只读回读**：`mirror_hf.py --check` 只输出 PLAN（`remote_files/sha` 为 `None`），不连远端。只读回读用 `GET https://huggingface.co/api/models/<repo>/revision/main`（`sha` + `siblings.Count`）。
5. **清单连锁**：批次中途新增交付件（如回执 JSON）会 +1 计入 `SHA256SUMS`（`holo_entries`），须整链重建 `build_b8_dual_sync → build_b9_zip --check（两次一致=不动点）→ five_site_dna build → verify`，再收尾提交（2）、再推送。`REPO_FILES`/`PKG_FILES` 为固定集合，新增件**不**改变 `repo 171 / package 28`。
6. **校验器自动产物**：`v3_gate --json` / `check_dimension_lock` 每次运行会改写 `benchmarks/*`（运行记录），按惯例还原不提交；收尾提交只含清单件（`SHA256SUMS` / `dual_repo_sums` / `b8_dual_sync` / `five_site_manifest` / 本批校验回执）。
7. **契约既有漂移**：`tests_contract` 中 `test_10_no_new_pack` 断言 `EXTRA_PACK_ORDER==11` 实际 12，系 V9 注册扩展包时契约未同步的既有漂移。判据优先：只记录不修改，交付说明如实披露；是否同步修契约需用户拍板。
8. **A10 自指天然**：`verify_v44` 首跑必红（`drift` 含刚写入的清单件），`five_site_dna build` 重建 manifest 后收敛 13/13——首跑红是结构性的，不是缺陷。
9. **回执刷新范式**：`files`/`files_count` 必须同源取自向量海 `manifest.json`（`dict(old)` 铺底 + `update`，`history` 追加用 `isinstance(h, dict)` 守卫）；`S2_gitee` 以实际 `ls-remote` 回读为准，受阻如实写「待补推」。
