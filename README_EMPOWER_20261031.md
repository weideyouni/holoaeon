## 二、低版本硬件个人用户快速使用说明（升级版）

### 2.1 健康自检表（动手前 60 秒）

| 检查项 | 及格线 | 怎么做 | 不合格怎么办 |
|---|---|---|---|
| Python 版本 | 3.8+（老机器选 3.8.10 32 位） | 终端 `python --version` | 到 python.org 装，勾选 Add to PATH |
| 空闲内存 | ≥ 512MB | 任务管理器看内存 | 关掉多余程序；纯骨架仍可跑 |
| 磁盘 | ≥ 100MB 即可 | `dir` 看剩余 | 项目本身极小，放心 |
| 中文环境 | 终端不乱码 | 跑示例看输出 | `chcp 65001` 切 UTF-8 |
| 路径 | 纯英文路径 | 项目所在路径检查 | 移到 `D:\holoaeon` 这类路径 |
| 杀毒提示 | 零网络零系统写入 | 源码可全审 | `python scripts/redline_scan.py` 自证清白 |

### 2.2 三条启动路线（按你的硬件选一条）

| 路线 | 硬件前提 | 启动命令 | 效果 |
|---|---|---|---|
| **路线 A · 纯骨架** | 512MB 内存、无网 | `python examples/01_basic_matrix.py` | 全部核心功能，AI 回答暂缺 |
| **路线 B · 本地大脑** | +4GB 内存 + 约 4GB 硬盘 | `ollama pull qwen2.5:0.5b` → `python bridges/quickstart.py --ask "用一句话解释什么是阴阳"` | AI 回答本地生成，仍免费离线 |
| **路线 C · 云端大脑** | +网络 + API 密钥 | 配 `HOLOAEON_API_KEY` 环境变量（密钥只进环境变量） | 接豆包/千问等云端模型 |

### 2.3 老机器运维三条军规

1. **先自检再动手**：任何报错先查 2.1 表，八成是路径/编码/PATH 三件事；
2. **跑之前先备份**：改动前 `git stash` 或复制一份目录，回滚永远有底；
3. **看不懂就贴回执**：把 `launch_local.py status` 输出原样贴给任何人，比描述问题高效得多。

## 三、内部融合 × 外部融合：本地全量打通操作指南

"内部融合协议 + 外部融合协议全量打通"不是口号，是本地可执行的一条命令链：

```bash
python scripts/launch_local.py status            # ① 全家福健康报告（runtime/agents/skills）
python scripts/launch_local.py demo              # ② 内外部融合全链路演示（本机实测，见下）
python scripts/launch_local.py run "你的任务"     # ③ 提交任务，自动选智能体
python scripts/launch_local.py hotplug optimization  # ④ 不重启热插拔优化包
python scripts/launch_local.py selftest          # ⑤ 24 组自检
```

### 3.1 本次实测回执（2026-10-31，本机 Windows）

```
内部融合协议（Internal Fusion）：心跳 → 图 → 总线 → 记忆
  心跳一拍完成；图节点数：25；图边数：57；总线已注册地址数：25；记忆条目：0
外部融合协议（External Fusion）：模型后端路由（离线决策）
  低成本任务路由 -> local；长上下文任务路由 -> cloud
端到端任务（确定性技能）
  all_ok: True — writing_editor ok {chinese_chars:15, sentences:1}
```

**读回执的三层含义**：
- **内部融合**=组件在进程内经信封/总线通信、由图编排、共享记忆、心跳同步，全程在守卫之后；
- **外部融合**=`ModelAdapter` 对本地与云端后端做**离线**路由决策（低成本→本地、长上下文→云端），
  不联网、不猜、不带内置密钥；
- **端到端**=任务文本经守卫 → 匹配智能体 → 调用确定性技能 → 返回结构化回执，全程可复现。
